一句话
════════════════════════════════════════════════════════════════════

你的录音、逐字稿、笔记、API Key 全部只存在你自己的电脑上。
本软件没有任何服务器，不收集、不上传、不回传任何使用数据。

════════════════════════════════════════════════════════════════════
你的数据存在哪
════════════════════════════════════════════════════════════════════

装在默认位置时，数据在：

    %LOCALAPPDATA%\LectureNotes\data\

（也就是 C:\Users\你的用户名\AppData\Local\LectureNotes\data）

只有一个例外：如果你在程序目录里自己建了一个 data 文件夹（或者从旧机器
连数据一起拷过来），程序就用那一个，方便做绿色版：

    程序目录\data\

注意是「看到 data 才用」，不是「能写就自己建一个」。所以你把程序解压到移动
硬盘或 U 盘上，它也不会在上面凭空长出一个数据目录。

装完想换地方，可以在 设置 → ③ 存储位置 里改：录音和模型缓存各自能搬到别的
盘，默认不动就一直在上面那个 %LOCALAPPDATA% 位置。

这个目录里有：
  · lectures\<录音 id>\audio.*      你的原始音频
  · lectures\<录音 id>\transcript.json  逐字稿
  · lectures\<录音 id>\note.json        笔记
  · config.json                     你的设置和 API Key
  · models\                         下载的本地转写模型
  · runtime.json                    程序运行时的端口和入口钥匙

卸载软件不会删除这个目录。想彻底清掉，自己把整个 LectureNotes 文件夹删掉。

════════════════════════════════════════════════════════════════════
什么时候会联网
════════════════════════════════════════════════════════════════════

只有这几种情况：

1. 你选了「云端转写」并点了「开始转写」
   你的音频文件会发送给你配置的那家服务商（比如硅基流动）。
   走的是它公开的 API 地址，我们不在中间。

2. 你选了「AI 笔记」并点了「生成笔记」
   逐字稿文字会发送给你配置的大模型服务商。

3. 你选了「浏览器本地 Whisper」且模型还没下载
   会从 hf-mirror.com（HuggingFace 的国内镜像）下载模型文件。
   这只是下载，不上传你的任何东西。

4. 你点了设置里的「测试连接」
   会向你填的那个接口地址发一个极小的试探请求，验证 Key 能不能用。

除以上四种，本软件不会主动联网。没有埋点、没有统计、没有自动更新检查
（升级靠你自己下载新安装包）。

════════════════════════════════════════════════════════════════════
API Key 怎么存的
════════════════════════════════════════════════════════════════════

存在你的 data\config.json 里，明文。因为程序要用它去调 API，不加密。

安全边界：
  · 你的电脑上有别的软件能读这个文件，它就能看到 Key。装软件前先想想
    这台机器的可信度。
  · 本软件的网页界面只监听本机时，Key 在界面上能直接看到（方便你核对）。
  · 如果你用 --host 0.0.0.0 让手机/平板也能访问，那么：
      - 局域网内的人拿不到 Key 明文，只能看到 sk-cik…aatz 这样的掩码
      - 管理 Key 的接口只接受来自本机的请求
  · 界面和接口都不会把 Key 写进日志。

入口钥匙：
  程序每次启动会生成一个随机端口（20000-39999）和一把随机入口钥匙，
  网址长这样：http://192.168.1.4:25994/8gvqzxe4nv/
  没有这把钥匙，局域网里别人扫到端口也只会看到「页面不存在」。
  钥匙存在 data\instance.json，只在你本机。

════════════════════════════════════════════════════════════════════
关于第三方服务商
════════════════════════════════════════════════════════════════════

你一旦选了云端转写或 AI 笔记，数据就离开了你的电脑，进入第三方服务商
的服务器。它们怎么处理、存多久、给谁看，由它们自己的隐私政策决定，
不由本软件决定。

建议你先读一遍你打算用的那家的隐私政策。对敏感内容（未公开的研究、
病历、商业秘密），建议用「浏览器本地 Whisper」或「本机大模型」，
全程不出本机。
