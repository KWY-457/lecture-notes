# 讲义笔记 · API 接入教程（完整版）

适用版本：本机运行版「讲义笔记 LectureNotes」
价格与链接核对日期：**2026-10-21**

这篇文档给「想认真读完再动手」的人看。全程只做三件事：选一家服务商 → 申请 API Key → 填进软件并测试。不需要写代码，不需要改配置文件。

---

## 一、先花两分钟搞清楚两个词

### 转写

**转写 = 把录音变成文字**。也就是「逐字稿」。

你有两条路：

- **本地转写**：软件在你电脑的浏览器里跑 Whisper 模型。免费、不联网、录音不出本机。代价是要先下载几百 MB 到 1.3GB 的模型，转换过程中很吃内存和显卡性能。
- **云端转写**：把音频上传给服务商，服务商转好把文字发回来。按音频时长（分钟数）计费，你电脑几乎不干活。代价是录音要上传，而且要花钱（或者用免费额度）。

### AI 润色

**AI 润色 = 用大模型把逐字稿整理成有条理的复习资料**。软件把上万字的逐字稿发给大模型，模型输出带主题、重点、考点的书面笔记。默认不点也会生成一份离线笔记（本地挑重点、不花钱）；「AI 润色」是在那份的基础上，把口语整理得更通顺。

同样两条路：

- **本地笔记**：在自己电脑上跑大模型。免费、不联网、文字不出本机。代价是常驻要占约 6GB 显存，低配电脑基本跑不动，跑起来也慢。
- **云端笔记**：把逐字稿发给服务商的大模型。按 tokens 计费（token 是模型处理文字的计量单位，中文大约一个字算一到两个 token），几乎不占你电脑资源。

> 一句话总结：**本地省钱但吃硬件，云端吃钱但不吃硬件。**

## 二、软件里只有四家

这是 0.9.0 版的一大变化：服务商从十一家收成四家，而且**四家全部「转写 + 笔记都能做」**。

| 服务商 | 转写 | AI 润色 | 要不要联网 | 要不要显卡 |
| --- | --- | --- | --- | --- |
| **本地** | 浏览器里跑 Whisper（三档可选） | 本机大模型 qwen2.5-7b（需先部署 4.4GB） | 不用 | 转写要，笔记要 6GB |
| **硅基流动 SiliconFlow** | SenseVoice（免费）/ Qwen3-ASR | Qwen2.5-7B / Qwen3-30B / DeepSeek-V3 / GLM-5.3-Flash | 要 | 不用 |
| **OpenAI** | whisper-1 | gpt-4o-mini / gpt-4o | 要（国内直连通常不通） | 不用 |
| **自定义** | 任何 OpenAI 兼容接口 | 任何 OpenAI 兼容接口 | 看你填的地址 | 不用 |

**为什么要收成四家**：以前十一家里有七家只能做一半（DeepSeek 只能笔记、Groq 只能转写），用户第一步就得先算「这家能不能干这个活」，界面还得为两种能力各准备一套模型列表。收完之后只剩一个下拉，选完这一家，下面**只显示这一家真正能调的模型**——不会出现「把别家的模型名填进来，请求直接 400」这种坑。

**那些被收掉的服务商怎么办**：DeepSeek、阿里云百炼、智谱 GLM、Moonshot Kimi、Groq、Ollama、LM Studio 全部收进「自定义」。它们本来就是 OpenAI 兼容接口，填个地址和模型名照样能用，见下面「六、自定义怎么填」。

### 推荐结论

**低配电脑直接走云端。** 具体建议：

- **转写选硅基流动 SenseVoice**：中文准、免费、不用显卡。
- **笔记也选硅基流动**，用卡片里默认的 Qwen2.5-7B-Instruct，一节课一两分钱。

这样本机**一个模型权重都不用下载**，也不用为了跑模型去升级电脑。

如果你的电脑有独显（6GB 以上显存）、而且你特别在意隐私，那本地模式也值得用。软件两种模式都支持，可以随时在设置里切换。

## 三、申请 API Key

### 0. 申请之前先知道三件事

1. **Key 就是钱**。拿到之后不要贴到群里、不要截图发出去。
2. **Key 只显示一次**。多数服务商在创建时完整显示一次，关掉页面就看不到了，先粘到记事本。
3. **新用户通常有免费额度**，金额各家会调整，以控制台为准。

### 1. 硅基流动 SiliconFlow（推荐首选）

| 项目 | 内容 |
| --- | --- |
| 注册 | https://cloud.siliconflow.com/ |
| API Keys 页 | https://cloud.siliconflow.com/account/ak |
| 文档 | https://docs.siliconflow.com/ |
| 支付 | 手机号注册，国内支付方式 |

1. 打开注册页，用手机号注册并登录。
2. 进「API Keys」页，点新建，复制 `sk-` 开头那串。
3. 余额和赠送额度在控制台里看。

**这家为什么排第一**：转写和笔记都能做，转写的 SenseVoice 免费、笔记的 Qwen2.5-7B-Instruct 一节课一两分钱，全程不用显卡。

### 2. OpenAI

| 项目 | 内容 |
| --- | --- |
| API Keys 页 | https://platform.openai.com/api-keys |
| 定价 | https://platform.openai.com/docs/pricing |
| 支付 | 需要海外支付方式 |

1. 打开 API Keys 页，新建密钥并复制。
2. 注意：国内网络直连通常不通，需要自己解决网络。这也是它排在硅基流动后面的原因。

### 3. 本地（不用申请任何 Key）

设置里服务商选「本地」就行。两件事要单独准备：

- **转写**：在「本地转写模型」卡片里选一档。large-v3-turbo（约 1.3GB）最准、抗噪最强，medium（约 800MB）省显存，small（约 250MB）低配能用。**首次转写时才下载**，那一次会比较慢。
- **笔记**：要先去「⑤ 环境自检」点部署本地大模型（qwen2.5-7b，共约 4.4GB，要 6GB 左右显存）。不部署也能用，只是「AI 润色」会自动退回离线引擎挑重点。

## 四、填进软件

**和以前版本最大的区别：只有一个「服务商」下拉，转写和 AI 润色共用这一家，一把 Key 两处通用。** 不用再分开填两遍。

### 步骤

1. 打开设置面板（右上角 ⚙）。
2. 「① 服务商」下拉，选一家。
3. 把 Key 粘进「API Key」框。如果界面提示「已保存（可直接修改）」，说明这里之前存过 Key，留空就不覆盖它。
4. 下面的「转写模型」和「笔记模型」是卡片，点一下就选中。
5. 需要的话，在「② AI 润色」的「额外要求」里写一句偏好，比如「这是法学课，请把法条编号写全；重点用【】标出」。这句话会附在提示词里。
6. 保存设置。

### 模型卡片怎么看

每张卡片有三样东西：

- **档位徽章**：`免费` / `性价比` / `更强` / `自定义`
- **价格量级**：比如「完全免费」「约 ¥0.8/小时」「一节课一两分钱」
- **一句代价**：这张卡不好的地方，比如免费的 SenseVoice 会写明「长段独白里会成片听错」

**这四个档位不是随便标的**，下面是实测依据：

| 模型 | 实测情况 |
| --- | --- |
| SenseVoiceSmall | 42.7 分钟中文课，30 秒转完，但把「习近平总书记」听成「心里标有问几」，笔记里会留乱码 |
| Qwen3-ASR-1.7B | 同一条录音，多认对 800 多字，「习近平」「灰心丧气」「诚信之星」都对，约 ¥0.8/小时 |
| Qwen2.5-7B-Instruct | 一句「说好」只花 1 个 token，最快最省 |
| Qwen3-30B / Qwen3-32B 这类 Qwen3 | 一句「说好」先写 300~400 字思考过程，那些字也算钱，慢且贵 |
| DeepSeek-V3 | 一句「说好」4 个 token，中文笔记质量高 |
| GLM-5.3-Flash | 限时免费，质量中上 |

**想填表里没有的模型**：点最后那张「其他（自己填）」，输入框会摊开，填什么用什么。

## 五、验证是否成功

### 笔记：点「测试连通性」

在「② AI 润色」这一节里，API Key 输入框旁边有一个「测试连通性」按钮。填好 Key 之后点它：

- **成功**会显示：`✓ 可用（模型回复：…）`，括号里是模型实际回的一句话。看到这个就说明地址、模型、Key 三样都对。
- **失败**会显示 `✗` 加具体原因，去下面的报错对照表里找。

失败时先检查这三样：服务商选对了没有、Key 是不是复制的时候多带了空格、余额是不是空的。

### 转写：先点「检查云端转写配置」

这个按钮**不发音频、不产生费用**，只告诉你地址、模型、Key 三样齐不齐。

想验证真实效果，用一小段录音试转（30 秒到 1 分钟就够）：

- 转写过程中，**进度条下方会显示这次用的是哪个引擎**，例如「硅基流动 SenseVoice」。
- 如果那行显示的是浏览器本地 Whisper，说明你选的还是本地模式，云端没生效。

### 报错对照表

| 看到的现象 | 含义 | 怎么办 |
| --- | --- | --- |
| `401` / `403` | Key 填错，或者没有余额/额度 | 重新复制一次 Key，注意别带空格；再去控制台看余额 |
| `404` | 接口地址填错了，或模型名不对 | 把服务商重新选一次让它自动填地址；模型名照抄官方文档 |
| `429` | 免费额度被限速了 | 等几分钟再试，别连着点 |
| 超时 | 网络问题，或者音频太长 | 检查网络；把长录音剪短再传 |
| `未配置云端转写 API Key` | 忘了粘 Key | 到「① 服务商」把 Key 填上并保存 |
| 提示「未配置云端转写地址」 | 选了自定义接口但地址空着 | 补上接口地址，或改成选一家现成的服务商 |

## 七、花多少钱（量级估算）

**以下是量级估算，不是精确账单。** 真实费用以各服务商控制台的账单为准。

### 先看一节课有多少字

1.5 小时的课，整理一次笔记大约消耗：

- 输入：约 **2.7 万 tokens**（逐字稿发给模型）
- 输出：约 **0.9 万 tokens**（模型写出来的笔记）

### 硅基流动的价格

硅基流动的单价会随活动和模型档位调整，官网上没有一张稳定的公开价目表，所以软件里写的是量级而不是精确数字。实测下来：

- **Qwen2.5-7B-Instruct**：整理一节课通常在**一两分钱**以内
- **Qwen3-30B / DeepSeek-V3**：贵一档，一节课**几毛钱**以内
- **GLM-5.3-Flash**：限时免费
- **SenseVoice 转写**：免费
- **Qwen3-ASR-1.7B 转写**：按音频时长 ¥0.00022/秒，**约 ¥0.8/小时**

具体以控制台的账单为准。

### OpenAI 的价格

来源：https://platform.openai.com/docs/pricing（2026-10-21 核对，按 1 美元≈7.1 元折算）

| 模型 | 输入 | 输出 |
| --- | --- | --- |
| `gpt-4o-mini` | $0.15 / 百万 tokens（约 1.07 元） | $0.60 / 百万 tokens（约 4.26 元） |

按上面的量级算：`gpt-4o-mini` 整理一节课**几毛钱**，`gpt-4o` 贵十几倍。

### 转写的费用

转写按**音频时长**计费，不同服务商单价不同，以各家控制台为准。用免费额度先试是最稳的做法。

## 八、省钱技巧

1. **先用免费档试**：硅基流动的 SenseVoice 转写免费、GLM-5.3-Flash 笔记限时免费。确认效果满意再充钱。
2. **别一开始就点 Qwen3 系列**：Qwen3 答之前会先写几百字思考过程，那些字也算钱。默认的 Qwen2.5-7B-Instruct 反而最快最省。
3. **一节课的转写和笔记只做一遍**：跑完就点「导出 Word」把 .docx 存好（Word / WPS 都能打开，可另存 PDF），别为了微调反复重跑。
4. **长录音先剪掉无关部分再上传**：转写按分钟计费，剪掉课间休息和闲聊，账单直接变小。
5. **转写要更准就花 ¥0.8/小时**：免费的 SenseVoice 在长段独白里会成片听错，重要课程可以选 Qwen3-ASR。

## 九、API Key 安全

- **Key 存在哪**：保存在你自己电脑的数据目录里，默认是 `%LOCALAPPDATA%\LectureNotes\data\config.json`（跟其它软件一样在 C 盘），实际位置可以在 设置 → ③ 存储位置 里看到，属于本机文件。
- **不会外传**：软件本身不会把你的 Key 发给服务商之外的地方。Key 只在你调用那家服务商时随请求发出去。
- **本机能看完整 Key**：在跑服务的那台电脑上打开设置，输入框里就是完整 Key（方便你确认「Key 还在」）。
- **手机/局域网只看得到掩码**：从手机访问时，界面只显示 `sk-cik…aatz` 这样的掩码，服务端也不会把明文下发。
- **不随笔记导出**：导出的 Word 笔记里不含 Key；整个数据目录拷走才是完整备份，注意别把这个目录随手发给别人。
- **不要泄露**：不要把 Key 贴到微信群、QQ 群、论坛，也不要截图发出去。Key 就是钱。
- **怀疑泄露就吊销**：进服务商控制台的 API Key 页面删掉旧 Key，重新建一个，再填回软件。删掉之后旧 Key 立刻失效。

## 十、常见问题

**没有信用卡能用吗？**
可以。硅基流动用手机号注册，国内支付方式更灵活。OpenAI 需要海外支付方式，而且国内直连通常不通。

**转写和笔记能用不同的服务商吗？**
软件里现在共用一家。如果确实要拆开（比如转写用硅基流动、笔记用 DeepSeek），把笔记那家填成「自定义」服务商，地址和模型手填即可。

**断网还能用吗？**
本地模式可以，云端模式不行。云端模式本来就是把音频或文字发给服务商，没网就没法用。临考前在没网的自习室，记得提前把笔记跑完导出来。

**大概花多少钱？**
按量级估算：硅基流动的 Qwen2.5-7B-Instruct 整理一节课一两分钱；OpenAI 的 gpt-4o-mini 几毛钱，gpt-4o 贵十几倍。转写这边 SenseVoice 免费，Qwen3-ASR 约 ¥0.8/小时。具体以控制台为准。

**本地模型和云端能混用吗？**
能。比如转写用云端（快），笔记用本机模型（免费、隐私好）。不过因为现在共用一家服务商，混用时要把其中一边选成「自定义」并手填地址。

**换了服务商，旧 Key 要删吗？**
在软件里覆盖成新 Key 就行。至于服务商那边的旧 Key，不用了建议去控制台删掉，少一个泄露面。

**为什么设置里看不到以前那些服务商了？**
0.9.0 把只能做一半的服务商都收进了「自定义」。你的老配置会自动迁移过来，Key 不用重填，见上面「六、自定义怎么填」的最后一段。
