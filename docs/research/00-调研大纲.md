## 一、调研范围（六个方向）

1. **国内转写竞品**：讯飞听见、通义听悟、飞书妙记、腾讯会议转写、剪映字幕、手机录音转写 App——UI/功能/底层/定价/分发

3. **笔记/导图赛道**：Notion、Obsidian、印象笔记、幕布、GoodNotes/Notability（录音回放定位）、学习通/雨课堂、XMind、ProcessOn、AI 自动导图先例、Mermaid/Markmap
4. **发售合规收款**：软著登记、ICP/算法/生成式 AI 备案边界、个保法、收款渠道（微信/支付宝/爱发电/Afdian/Paddle/Lemon Squeezy）、定价授权、EULA/隐私政策、税务、盗版

## 三、结论汇总区（六路全部归档，2026-10-15 定稿）

1. **竞品都在做什么？我们缺什么？**（02/04）
   - 头部全在「云 + 订阅」，转写本身不赚钱，赚钱在转写后的「整理」；讯飞把转写会员与 AI 整理会员拆两层卖被骂。
   - 用户痛点排序：说话人错配 > 整段丢失 > 数字/专名错 > AI 擅自润色改口 > 额度口径混乱 → 我们的「逐字稿可靠 + 可回溯」要放在「一键成稿」之前。
   - 我们没有但学生真需要的（按优先级抄）：① 词级点击定位音频（飞书妙记）② 重点标记一键提取（通义听悟）③ 章节速览点击跳片段 ④ 热词库/课程词库（讯飞热词 ≤200 个）⑤ 说话人筛选+跳过空白（课堂单讲者场景可后置）。
2. **UI 结构怎么组织？**（02 可借鉴清单 UI 组 8 条）三栏布局方向对，但要补「词级定位」「章节速览」「前三分钟免费试看」这类低门槛入口；导图要做成「大纲=唯一数据源、导图只是视图」（幕布范式）。
3. **我们的技术栈在行业里的位置？**（03/07）FunASR 官方 micro-CER：SenseVoiceSmall 7.81 vs whisper.cpp large-v3-turbo 23.15 —— 中文直用 Whisper 错字率高；我们靠抗噪+清洗+大模型校对补偿，走「零依赖便携」路线，与 Buzz/Vibe/言灵/RecText AI 2 同族。03 补充对比：faster-whisper int8+batch8 把 13 分钟音频压到 51 秒（依赖 Python/CUDA，不适合捆绑）；whisperX 数字/符号词无法对齐、中文需自找 wav2vec2、要 CUDA 12.8（第一版不用）；pyannote 需 HF token+gated（不捆绑）；sherpa-onnx 是中文 SenseVoice 的轻量落地路径（备选）。**结论：Windows 上没有商业级本地 Whisper 桌面工具（MacWhisper 仅 macOS），我们「浏览器 Whisper + 零依赖 Node + 抗噪清洗校对」是当前 Windows 本地课堂转写唯一的商业形态；云端只做「整理」不做「转写」。**
4. **定价先例？**（09/07）买断成功先例密集：白描 30/50 元、录音啦 9.9 月/59.9 年/629 永久、**言灵 ¥18 一次买断**（App Store 原文核实）、RecText AI 2 9,980 日元买断。→「本地转写买断 + 云端 AI 按量充值」组合成立；行业标准价构：ASR 0.6 元/小时、AI 整理逐项 0.064 元/小时（通义听悟）。
5. **代码 → 卖钱的完整路径？**（05/06）资质：软著官方免费登记（60 日内，代办 ~500 元）；纯软件下载不需 ICP 备案，建官网才需非经营性备案（免费 7-20 工作日）；学习辅导工具定位 → 无需自办算法备案，用已备案模型 API + 履行标识/协议/未成年人义务。收款：爱发电 6% / 面包多 2%+0.1 元起步 → 月流水过万办个体户（免费、线上 1-3 工作日）走微信经营收款码（费率低至 0.1%）；微信小微商户 API 官方明文「暂不支持线上行业」，慎用。税务：小规模月 ≤10 万免增值税、个体户年所得 ≤200 万部分个税减半（均至 2027-12-31）。授权：机器码+RSA 签名 license 离线激活。打包：Electron 44 + electron-builder NSIS + electron-updater + bytenode + OV 证书（¥3700/年）；渠道：Microsoft Store 个人开发者免费、联想开放平台、太平洋下载中心。
6. **用户怎么拿更新？**（06）electron-updater generic provider + latest.yml Ed25519 强制签名 + blockmap 4KB 差分；模型权重自研 Range 断点续传（LM Studio 是唯一支持暂停续传的先例）。
7. **怎么防破解？**（06）本地架构代码天然在盘上 → bytenode 字节码（注意 Electron ≥42 要 compileElectronMainCode）+ machine-id 授权；模型权重本就开源，护的是工程与更新服务。
8. **合规底线？**（07 13 条清单）纯本地、无账号 = 备案风险最小形态；云端生成必须只接已备案模型 + 公示备案号 + AI 内容标识（2025-09-01 办法）；隐私政策/用户协议必须正式成文（现状盘点 §五.8 是缺口）。
9. **「本地优先」能当卖点吗？**（02/07/09）能，且是被验证过的：网易见外 2020 关停、搜狗录音笔 2025 停服、讯飞语记 2026 缩水 → 用户连吃三刀；言灵 4.9 分卖 ¥18 买断、RecText 官方主打「机密音频也安心」。话术：「录音不出本机，笔记只属于你」「买断永久，不怕停服」。
