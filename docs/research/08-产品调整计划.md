## 一、产品定位（一句话版 + 依据）

**面向学生的本地优先课堂笔记工具：录音不出本机，买断永久可用，转写免费、AI 整理按量可选。**

- 差异化打「本地优先」：头部全部云+订阅，且用户刚被网易见外（2020 关停）、搜狗录音笔（2025 停服）、讯飞语记（2026 免费缩到 5 分钟）连伤三轮 → 「不怕停服、不卖数据」是现成最强卖点（02）。
- 课堂场景几乎空白：竞品全围会议转，Windows 本地课堂笔记无直接对手（02）；国际上同样空白——Windows 无商业级本地 Whisper 桌面工具（MacWhisper 仅 macOS），我们是当前唯一形态（03）。
- 「买断」有密集成功先例：白描 30/50 元、言灵 ¥18 一次买断（4.9 分）、RecText AI 2 9,980 日元买断、录音啦 629 元永久会员、MacWhisper €64 买断终身更新（学生 25% 折；Gumroad 买断 + App Store 订阅双 SKU）（09/02/03）。
- 收入结构学行业标准：本地转写=买断/免费（省下通义听悟 ASR 0.6 元/小时），云端 AI 整理=按量充值（对齐 0.064 元/小时级的行业价）（02/09）。

## 二、功能优先级路线图

### P0 · 已具备（守住的底线）
1. 抗噪 → 本地转写（WebGPU+fp16 0.64× / CPU-WASM+q8 0.40×）→ 繁简+清洗+校对
2. 时间戳逐字稿 + 点击跳转回听（= 言灵核心卖点，我们已实现）
3. 双引擎笔记（离线启发式 / 云端大模型口语→书面语）+ 思维导图（已改吃 AI 结构）
4. 导出 Word（零依赖手写 OOXML）

### P1 · 调研后确认要补（抄谁、为什么）
1. **词级点击定位音频**（飞书妙记）：痛点排序里「说话人错配」第一，词级定位=校对神器（02）。当前只有段落级时间戳；落地方案：whisper.cpp -ml 1 词级时间戳（精度略低但够用），SRT 用 VAD 稳定边界兜底（03）。
2. **重点标记一键提取**（通义听悟「标记重点 → 右侧文档栏」）：学生复习工作流的刚需（02）。
3. **章节速览**（通义听悟章节速览点击跳片段）：长课 2 小时录音的导航刚需，我们已有主题分段数据，缺的是右侧速览 UI（02）。
4. **热词库 / 课程词库**（讯飞听见热词 ≤200 个、单个 1-16 字符）：把「闭卷考试」「思想政治」这类高频词喂给转写能直接压掉 BJR 类误识（02/现状盘点遗留 1）。
5. **前三分钟免费试看**（讯飞听见机制）：卖点转化设计，发售后做（02）。
6. **导图「大纲=唯一数据源」**（幕布范式）：导图只是大纲的视图、可编辑回写大纲；当前导图只读（04）。
7. **词级回放聚光灯**（GoodNotes Note Replay：已播全显/未播淡化）：Windows 端空白，我们的差异化 UI 机会，P2（04）。

### P2 · 长线
- 说话人分离（课堂单讲者场景价值低，后置；方案=自研 VAD+能量二分类区分主讲/他人并允许手动改标，不捆绑 pyannote——它需 HF token+gated 协议）（02/03）
- PDF 一键导出（Word 可另存，但一键 PDF 是用户预期）（现状盘点遗留 7）
- 手机端（录音在主用设备，手机 App 是分发杠杆；先做 Vibe 式 QR 码录音回传，零开发成本）（03）
- watch folder 零操作转写（文件丢进监听目录自动转，Vibe/MacWhisper 先例）（03）

| 档位 | 内容 | 参考先例 |

- 定价心理支持：YouGov 约 7 成倾向一次性付款；美兰德 LLM 用户 50.9% 偏好年付/买断（07）。

- 红线（04 的翻车教训）：免费封数量不封核心；到期只回收 AI 与时长，绝不锁笔记数据；「数据永远在你硬盘上」写进产品页。

## 四、发布路线（开发 → 发售 → 更新）

1. **打包**：Electron 44.x + electron-builder 26.x（NSIS per-user）——WebGPU 是 ASR 命脉，Tauri 对 WebGPU not_planned（官方 issue #6381），且 server.mjs 迁 Electron main process 零改造（06）。
2. **模型分发**：方案 A（小 exe + 首次联网下载），自研 Range 断点续传（LM Studio 是唯一支持暂停续传的先例；Ollama #13167、AnythingLLM #4192 都不支持）（06）。
3. **更新**：electron-updater 6.x generic provider + latest.yml Ed25519 强制签名 + blockmap 4KB 差分（06）。
4. **防破解**：bytenode 字节码（Electron ≥42 主进程要 compileElectronMainCode()、≥43.5.1 preload 要 electronRenderer:true，.jsc 绑定 V8 版本每次升级重编译）+ HKLM MachineGuid 机器码授权（06）。
5. **签名**：锐安信 OV 证书 ¥3700/年 + 时间戳签名；SmartScreen 声誉按下载量累积、EV 也会警告，需长期积累（06）。
6. **渠道**：Microsoft Store（个人开发者 2025-09-11 起免注册费、2.5 亿月活、MSIX 微软托管分发、游戏外自建内购 0 抽成）（09）；联想开放平台自助入驻（PC 应用暂不强制软著）；太平洋下载中心免费自助（需营业执照+手持身份证+官网内链）；华军无公开自助入口（06）。
7. **收款**（05）：起步爱发电（6%）+ 面包多（2%+0.1 元/笔）双开，零门槛、平台代办税务、有自动发货；月流水过万办个体户（免费、线上 1-3 工作日）→ 微信经营收款码（无需执照、费率低至 0.1%、T+1）或支付宝当面付（个人可签约）；微信小微商户 API 官方明文「暂不支持线上行业」慎用；Stripe 大陆个人开不了户，海外走 Paddle（5%+$0.50）或 Gumroad（10%+$0.50）。
8. **系统边界**：Win10 1809+/Win11 x64（Win7 双路不可行：Electron 22 后不再支持、WebView2 仅 Win10/11）（06）。
9. **云端兜底策略**（03）：OpenAI 正在退役 whisper-1（2027-02-26），替代品 gpt-transcribe $0.0045/min 没有词级时间戳/SRT/说话人 → 云端只做兜底转写与「整理」，字幕/词级时间戳/说话人一律本地生成；Cloudflare @cf/openai/whisper $0.0005/min 是批量兜底最便宜的公开选项（AWS $0.024/min 贵 48 倍）。
10. **防冒名域名**（03）：whisperdesktop.com 是冒充 Const-me 的钓鱼站——上线时注册防冒名域名并在官网声明唯一正版下载入口。

## 五、合规底线（05 交叉核实后的定稿）

- 学习辅导工具定位 → 无需自办算法备案：用**已备案模型 API** + 履行标识/协议/未成年人义务即可（阿里云官方场景 1；加「分享社区」才触发安全评估+算法备案）（05/07）。
- AI 输出按 2025-09-01 标识办法加「由 AI 生成」标识 + 隐式元数据；导出文件保留显式标识（05）。
- 纯本地、无账号 = 备案风险最小形态（《生成式AI暂行办法》第 2 条「未向境内公众提供的」不适用）（07）。
- 隐私政策 / 用户协议 / EULA 三份文档必须正式成文；EULA 不得写「最终解释权归本店所有」（《网络交易监督管理办法》第 21 条明文禁止）；「数字化商品不支持七天无理由退货」须下单前显著确认（05）。
- 录音仅主动触发、不训练、可导出可删除；声纹属敏感个人信息（PIPL 第 28 条）；不满 14 周岁需监护人同意条款（05）。
- 话术备案：「录音不出本机，笔记只属于你」（07）。
- 许可证义务：whisper/onnxruntime-web/Electron 均 MIT、transformers.js Apache-2.0 → 附 LICENSE 副本 + NOTICE + 修改声明（06）。
- 软著：官方免费登记（60 日内），不登记也能卖但维权举证难 → 至少 Git 完整提交历史 + 可信时间戳（05）。
