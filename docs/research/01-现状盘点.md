# 讲义笔记 · 现状盘点（调研基准线）

> 本文件是产品调研的「基线」：先如实记下我们产品今天长什么样，后面六路竞品调研回来之后，逐条对照「别人有什么、我们有什么、差在哪」。
> 整理时间：2026-10-15。所有路径相对 `D:\Download\dev\lecture-notes\`。

## 一、产品一句话

把课堂录音变成能直接复习的笔记：手机录音导入 → 自动转文字 → 自动切主题、挑重点 → 生成带时间轴的笔记（Word 导出）。全程本地完成，零外部依赖。

## 二、技术形态（重要：这不是传统软件）

| 维度 | 现状 |
| --- | --- |
| 本质 | 本地网页 + 本地 Node 服务（不是桌面应用，不是 SaaS） |
| 前端 | 纯静态：`public/index.html` + `app.js`（66.5 KB / 45 个函数）+ `app.css` + 6 个功能模块 |
| 后端 | `server.mjs`（1039 行，只用 Node 内置模块，零 npm 依赖） |
| 运行时 | 自带 `runtime\node.exe`（89.24 MB），系统没装 Node 也能跑 |
| 启动方式 | `启动.vbs`（Edge `--app` 模式开无地址栏窗口，UTF-16LE+BOM 编码）、`start.cmd`、`停止.vbs`、`启动（可调试）.vbs` |
| 端口 | 8788；同时开放局域网地址（手机同 Wi-Fi 上传录音） |
| 数据 | `data\lectures\<id>\` 下 `meta.json` / `transcript.json` / `note.json` / `audio.*`；`data\config.json`；模型缓存 `data\models\` |
| 卖点 | 「双击就能跑」：不用装 Python / Node / ffmpeg / Docker / 不注册账号 |

## 三、现有功能清单（按用户旅程）

1. **导入**：手机录音 m4a/mp3/wav/amr/webm 拖拽上传、电脑麦克风直接录音、局域网手机上传、示例录音体验
2. **转写（双引擎）**
   - 本地：浏览器内 Whisper（transformers.js + ONNX）——WebGPU 用 fp16（0.64× 实时、中文可读）、CPU/WASM 用 q8（0.40×）；q8+WebGPU 会出乱码（已按设备自动选 dtype）
   - 云端：13 家服务商注册表（硅基流动 SenseVoice / Groq / OpenAI 兼容 / 自建等），带价格提示、申请教程弹窗、配置自检
   - 前置：纯 JS STFT 抗噪（Ephraim-Malah + Otsu VAD + 工频陷波），不改变采样点数
   - 后处理：繁转简（2965 字表）、白名单字符清洗、大模型校对（音近错字 + 拼音首字母误识，分块 5000 字，失败逐级降级）
3. **笔记（双引擎）**
   - 离线引擎（`summarize.js`）：TextRank 重点句、主题分段、关键词、概念定义、老师强调/考点/作业/自测题、一句话概要——纯启发式，口语原样保留
   - AI 引擎（`llm.js`）：MAP/REDUCE 分块 + DIRECT 直出，口语→书面语整译、三种风格（应试重点/提纲/康奈尔）、时间戳链接化
4. **思维导图**：从笔记「课堂脉络与重点」章节生成 Mermaid 树
5. **回听**：笔记里每个时间戳可点，音频直接跳转
6. **导出**：Word（.docx，零依赖手写 OOXML）；服务端还留着 note/txt/srt 旧分支（界面已不露出）
7. **工程性**：转写进度条（阶段权重 + 心跳 + 缓爬）、转写前自动腾显存（VRAM_NEED_MB=2500）、环境自检面板（WebGPU/Node/内存/模型缓存）、本地 llama-server 一键启停、全局错误 toast
8. **设置**：转写引擎（本地/云端）、模型与下载源（hf-mirror/jsDelivr 多源回退）、语言、降噪开关、LLM 服务商（13 家下拉 + 价格提示 + 预设自动填充）、笔记风格、重点条数

## 四、已测出的性能底线（质量报告 §7.8，同机实测）

| 跑法 | 相对实时 | 质量 |
| --- | --- | --- |
| WebGPU + fp16（turbo） | 0.64×（1 小时录音 ≈ 转 1.6 小时） | 中文可读，最好 |
| CPU/WASM + q8（turbo） | 0.40×（1 小时 ≈ 转 2.5 小时） | 中文可读 |
| WebGPU + q8 | 0.23× | 成段乱码，禁用 |

- 模型权重：turbo fp16 ≈ 1.5 GB，量化 ≈ 1.0 GB；首次使用需下载（已做镜像 + 磁盘缓存 + 断点续传）
- 云端转写：通常 1–3 分钟/小时录音，SenseVoice 约 ¥0.01/分钟级

## 五、遗留问题（如实记录，调研后对照竞品看怎么补）

1. **BJR 类拼音首字母误识**：turbo 转写仍把「闭卷考试」听成「BJR」；校对提示词已加规则 5，但尚未在真实数据验证
2. **62b4f73d 仍是 whisper-small 旧转写**（用户动作，待重转）
3. **笔记深度不随材料长度增长**：「理解脉络」在 188–321 字间波动，长课不会更详细
4. **不是 exe**：目前靠 Edge `--app` 壳，任务管理器显示为 Edge；用户已要求打包（方案 A：小 exe + 模型首次联网下载），尚未动工
5. **没有自动更新**：改代码 = 改文件夹，用户之间如何同步新版本完全没有方案
6. **没有授权/收款**：现在免费裸奔，无激活、无付费入口
7. **PDF 导出没有**（Word 打开可另存，但无一键 PDF）
8. **隐私合规文案**：README 有「音频不出本机」表述，但没有正式的隐私政策/用户协议
9. **长录音体验**：本地转写 1 小时要 1.6–2.5 小时，期间页面不能关；云端快但要走 Key 配置（对小白是门槛）
10. **课程字段**：还在（手动填），「课程定位」自动识别功能已按用户要求删除

## 七、产品定位现状（调研前自述）
