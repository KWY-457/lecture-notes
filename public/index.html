我的课堂录音

    把课堂录音，变成能直接复习的笔记把这节课的录音传到电脑上

    把手机里录的课导进来，自动转成文字、自动挑出重点，生成能直接复习的课堂笔记。手机上不用装 App、不用登录：选个文件传上去，转文字、挑重点、导出都在电脑上做。

    1. 手机录音：用手机自带的录音机上课录音（不用装 App）。
    2. 传到电脑：手机和电脑连同一个 Wi-Fi，用手机浏览器打开本页的局域网地址上传；或者直接微信/数据线拷到电脑。
    3. 自动整理：在本页点「开始转写」，转写完笔记会自动生成（重点 + 逐字稿 + 自测题），不用再点。
    4. 导出：点「导出 Word」，用 Word 或 WPS 打开就是一份排版好的复习笔记。
    1. 在电脑上录音：用手机自带的录音机上课录音，文件留在手机里。
    2. 点上面的按钮传上去：选文件、起个名字，传完这一步就结束了，手机会提示「已上传」。
    3. 回到电脑上处理：转写、生成笔记、导出 Word / PDF 都在电脑上做，手机上不用管。

    使用说明

    最快的用法

    1. 使用手机自带的「录音机」录制整节课（保持连续录制，中途无需暂停）。
    2. 课后让手机连接 Wi-Fi。先在电脑上打开 设置 → ④ 手机访问 把开关打开，下方就会显示该访问的地址：
      （开关打开后会显示）
    3. 在手机页面点「导入录音」，选中刚才录的文件，等进度条走完。传完记得回电脑把开关关掉。
    4. 回到电脑浏览器，打开同一条录音，点「① 开始转写」，转写完笔记会自动出现。
    5. 点「导出 Word」，用 Word / WPS 打开就是一份复习笔记，也可以在里面另存为 PDF。

    为什么转写建议在电脑上做？

    手机浏览器在 http 页面中没有麦克风权限，且本地 Whisper 依赖 WebGPU，手机端无法运行。因此：手机负责录音与上传，电脑负责转写与整理。若电脑配置较低，可在设置中改用云端转写接口。

    时间戳的用途

    笔记与逐字稿中的 12:34 均可点击，点击后音频将跳转到对应位置，便于回听核对。

    数据在哪？

    全部存在本地数据目录里（默认 %LOCALAPPDATA%\LectureNotes\data，装完想换盘就到 设置 → ③ 存储位置 改）：音频、逐字稿、笔记。不上传任何服务器（除非你自己开了云端转写）。整个目录拷走就是备份。

    长录音的注意事项

    • 单段建议 90 分钟以内；特别长的课建议按节次分开录、分开导。
    • 浏览器里做本地转写时，程序要把整段音频解码进内存，1 小时立体声大约占 1GB 内存。内存吃紧就改用云端转写。
    • 转写过程中请不要关掉这个标签页。
