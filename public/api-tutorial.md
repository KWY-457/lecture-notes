**云端 API 接入：三步走**

这个软件默认在自己电脑上跑模型，低配电脑会卡。换云端就是：把活交给服务商，你只出一把「API Key」。

API Key 是一串密码一样的字符，多数以 `sk-` 开头。它代表你的钱包，别外传。

三步：选一家 → 申请 Key → 填进软件并测试。

**先说两个词**

转写：把录音变成文字。本地转写免费、不联网，但要下几百 MB 到 1.3GB 模型、吃内存和显卡。云端转写是把音频上传给服务商，按分钟计费，你电脑毫无压力。

AI 润色：把逐字稿整理成有条理的复习资料。本地要常驻约 6GB 显存；云端是把文字发给服务商，按 tokens（字符的计量单位）计费，几乎不占你电脑。

**软件里只有四家可选**

| 服务商 | 转写 | AI 润色 | 要不要联网 |
| --- | --- | --- | --- |
| 本地 | 浏览器里跑 Whisper | 本机大模型（需先部署，约 4.4GB） | 不用 |
| 硅基流动 SiliconFlow | SenseVoice / Qwen3-ASR | Qwen2.5-7B / Qwen3-30B / DeepSeek-V3 / GLM-5.3-Flash | 要 |
| OpenAI | whisper-1 | gpt-4o-mini / gpt-4o | 要（国内直连通常不通） |
| 自定义 | 任何 OpenAI 兼容接口 | 任何 OpenAI 兼容接口 | 看你填的地址 |

四家都是**转写和笔记一起管**：选完服务商，下面只显示这一家真正能调的模型，不会出现「别家的模型填进来报 400」这种坑。

以前版本里的 DeepSeek、阿里云百炼、智谱 GLM、Moonshot Kimi、Groq、Ollama、LM Studio 现在都收进了「自定义」——它们本来就是 OpenAI 兼容接口，填个地址和模型名照样能用，见下面「自定义怎么填」。

**低配电脑就选这套**

- 转写：硅基流动 SenseVoice（免费）
- 笔记：硅基流动里选一张卡片，默认 Qwen2.5-7B-Instruct 就够

这样本机一个模型权重都不用下，也不用显卡。

**第一步：选一家，申请 Key**

**1. 硅基流动 SiliconFlow（转写和笔记都能用，先选它）**

1. 打开 `https://cloud.siliconflow.com/` 注册，手机号即可。
2. 进 API Keys 页：`https://cloud.siliconflow.com/account/ak`，新建一个密钥，复制。
3. Key 只完整显示一次，先粘到记事本。余额和赠送额度在控制台里看，以控制台为准。
4. 文档：`https://docs.siliconflow.com/`

**2. OpenAI（转写或笔记，国内直连通常不通）**

1. 打开 `https://platform.openai.com/api-keys` 新建密钥。
2. 定价：`https://platform.openai.com/docs/pricing`
3. 注意：国内网络直连通常不通，需要自己解决网络。这也是它排在硅基流动后面的原因。

**不想花钱、想在本地跑**

不用申请任何 Key。设置里服务商选「本地」，然后：

- 转写：在「本地转写模型」卡片里选一档。large-v3-turbo（约 1.3GB）最准，medium（约 800MB）省显存，small（约 250MB）低配能用。首次转写时才下载。
- 笔记：要先去「⑤ 环境自检」点部署本地大模型（qwen2.5-7b，共约 4.4GB，要 6GB 左右显存）。不部署也能用，只是「AI 润色」会退回离线引擎挑重点。

**自定义怎么填**

选「自定义」之后，两处地址都要自己填：

| 服务商 | 转写地址 | 笔记地址 | 常用模型名 |
| --- | --- | --- | --- |
| DeepSeek | 不支持转写 | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 阿里云百炼 | 不支持转写 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | 不支持转写 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`（免费档） |
| Moonshot Kimi | 不支持转写 | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| Groq | `https://api.groq.com/openai/v1/audio/transcriptions` | `https://api.groq.com/openai/v1` | `whisper-large-v3-turbo` |
| 自建 faster-whisper | `http://127.0.0.1:8000/v1/audio/transcriptions` | — | `large-v3-turbo` |
| Ollama | 不支持转写 | `http://127.0.0.1:11434/v1` | `qwen2.5:3b` |
| LM Studio | 不支持转写 | `http://127.0.0.1:1234/v1` | 软件里下载的那个 |

转写地址的规则：填到 `/audio/transcriptions` 结尾的完整地址。笔记地址填到 `/v1` 结尾（不带 `/chat/completions`）。

**第二步：填进软件**

设置面板里只有一个「服务商」下拉，转写和 AI 润色共用这一家，一把 Key 两处通用——不用再分开填两遍。

1. 打开设置面板（右上角 ⚙）。
2. 「① 服务商」下拉，选一家。
3. 把 Key 粘进「API Key」框。
4. 下面的「转写模型」和「笔记模型」是卡片，点一下就选中。每张卡上写着价格量级和一句代价，比如免费的 SenseVoice 会写明「长段独白里会成片听错」。
5. 保存。

想填表里没有的模型？点最后那张「其他（自己填）」，输入框会摊开，填什么用什么。

**第三步：测试，别急着上课**

**笔记这边**

- 点「测试连通性」。
- 成功会显示：`✓ 可用（模型回复：…）`。
- 失败会显示 `✗` 加原因，对照下面的报错表。

**转写这边**

- 点「检查云端转写配置」。它会告诉你地址、模型、Key 是否齐全（不发音频、不产生费用）。
- 或者导入一小段录音试转（30 秒到 1 分钟就够）。转写进度条下方会写明这次用的是哪个引擎，比如「硅基流动 SenseVoice」。看到它，说明云端这条路通了。

**报错对照表**

- `401` / `403`：Key 填错，或者余额/额度用完了。重新复制一次 Key，或去控制台看余额。
- `404`：接口地址填错了（或模型名不对）。把服务商重新选一次，让它自动填地址。
- `429`：免费额度被限速了。等一会儿再试，别连着点。
- 超时：网络问题，或者音频太长。先剪短一点再传。
- `未配置云端转写 API Key`：忘了粘 Key。

**省钱技巧**

- 先用免费档试（SenseVoice 转写免费，GLM-5.3-Flash 限时免费），确认效果再花钱。
- Qwen3 系列（Qwen3-30B 这类）答之前会先写几百字思考过程，那些字也算钱。只要归纳够用，默认的 Qwen2.5-7B-Instruct 反而最快最省。
- 一节课的转写和笔记只做一遍，点「导出 Word」存好，别反复重跑。
- 长录音先把无关部分剪掉再上传，按分钟计费的部分会少一些。

**API Key 安全**

- Key 保存在你自己电脑的数据目录里（默认 `%LOCALAPPDATA%\LectureNotes\data\config.json`，实际位置见 设置 → ③ 存储位置），不随笔记导出，不外传。
- 本机打开设置能看到完整 Key（方便你确认还在）；手机/局域网访问时只显示 `sk-cik…aatz` 这样的掩码，服务端也不会下发明文。
- 不要把 Key 贴到群里，也不要截图发出去。
- 怀疑泄露就去服务商控制台吊销旧的、重新建一个。

**常见问题**

没有信用卡能用吗？可以。硅基流动用手机号注册，支付方式更灵活。OpenAI 需要海外支付方式，而且国内直连通常不通。

转写和笔记能用不同服务商吗？软件里现在共用一家。如果确实要拆开（比如转写用硅基流动、笔记用 DeepSeek），把笔记那家填成「自定义」服务商，地址和模型手填即可。

断网还能用吗？本地模式可以，云端模式不行。云端模式本来就是把音频和文字发给服务商。

大概花多少钱？量级估算，不是精确账单。1.5 小时的课约 2.7 万 tokens 输入 + 0.9 万 tokens 输出。硅基流动的 Qwen2.5-7B-Instruct 整理一节课通常在一两分钱；OpenAI 的 gpt-4o-mini 换算下来约几毛钱，gpt-4o 要贵十几倍。转写按音频时长计费，各家不同，以控制台为准。

**价格与链接核对日期：2026-10-21**

各服务商可能调整价格和规则，请以官方页面为准。本教程不构成任何价格承诺。
